CyberLoader
===========

CyberLoader switches sets of Cyberpunk 2077 mods (profiles) on and off safely.
It keeps your mods in its own library and links them into the game, so turning a
profile off leaves no stray files behind, and it never overwrites a file it does
not own.

Getting started
  1. Open CyberLoader from the Start menu (or the desktop shortcut, if you made one).
  2. Drag a mod archive (.zip, .7z, .rar) or a mod folder onto the window to add it
     to your library. It is unpacked into its own folder and never run.
  3. Turn mods on or off, then press Apply. The game must be closed.
  4. Open Profiles in the side bar and press "New profile". The "Empty" profile is the plain game.

Where things are
  This folder          the program (safe to leave alone)
  data\ (or the folder you chose in Setup)
                       your mod library, profiles, trash and logs
  Your game folder is never modified except by Apply, and only with files
  CyberLoader recorded itself.

Uninstall
  Windows Settings > Apps > CyberLoader, or run Uninstall.exe in this folder.
  Your library is kept unless you tick the box to delete it.
